# Probability Lab

Open [`probability-lab.html`](probability-lab.html) for a neutral, browser-based probability learning tool. It simulates coin flips, six-sided die rolls, or a configurable Bernoulli event, and visualizes cumulative observed frequency against theoretical probability.

The simulator is educational only: it does not predict real outcomes, provide betting advice, or include wagers, prizes, or payment features. All trials run locally in the browser.

Run locally with:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080/probability-lab.html`.
