# Racing Game

A standalone neon racing game is available at [`racing-game.html`](racing-game.html).

## Controls

- **Arrow keys** or **WASD**: steer and accelerate
- **Touch devices**: use the on-screen controls
- Complete 3 laps without colliding with rival cars

Serve the repository locally:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080/racing-game.html`.
