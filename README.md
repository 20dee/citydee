# NovaFX

A polished, responsive forex trading dashboard built with plain HTML, CSS, and JavaScript.

## Run

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

The app uses simulated market data and demo trading actions; it does not connect to a brokerage or execute real trades.
